## 초안 원칙 (기존 검토본 235행의 결정을 따름)

- MeSH `… Neoplasms`와 Solid Tumo(u)r는 기본 **종양**, 시험 제목·공식 제목에 악성 단서가 있을 때만 **암**(`title_exception`에 기존과 같은 정규식). 해당 49행
