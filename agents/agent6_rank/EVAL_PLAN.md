### 갱신 반응 (`eval_update`, `update_pairs.csv` 36쌍)

dev에서 시험 판정이 바뀐 짝은 1쌍뿐입니다. 그래서 순위 대신 기준 단위로 잽니다.

- `unaffected_stable`: 인용한 노드 내용이 두 그래프에서 완전히 같은 문장이 글자 그대로 유지되는 비율입니다. 틀 문장은 **환자용 471/471, 의료진용 242/242 (100%)**입니다. 결정적으로 쓰는 생성기의 정상 상태이며, LLM 브리핑에서 이 값이 떨어지는 몫은 다시 쓰기 때문에 생긴 흔들림입니다.
- `verdict_changed`: 판정(status·reason·action)이 바뀐 기준을 인용한 문장 중 바뀐 비율입니다. 틀 문장은 환자용 53.8%, 의료진용 82.4%입니다. 참고값으로만 봅니다. 이유만 바뀌면 "항목 5개"가 그대로인 것이 맞기 때문입니다.
- 시험 판정이 바뀌거나, 브리핑에 들어오거나 빠지거나, 순위 위치가 바뀐 시험은 그 시험 문장 전체를 판정 변경으로 셉니다.
- 변형 대상 기준(`variant_targets.csv`): 36쌍 모두 그래프에서 대상 기준의 판정이 바뀌었습니다.
  - 환자용: 대상 시험이 브리핑에 있는 14쌍 중 11쌍에서 문장이 바뀌었습니다. 나머지 22쌍은 대상 시험이 환자용 상위 5개에 없거나 순위 밖입니다.
  - 의료진용: 대상 시험이 있는 13쌍 모두에서 문장이 바뀌었습니다. 순위 밖 시험이라도 near-miss 목록에 있으면 5쌍에서 더 반영됩니다.

### 이 평가로 드러난 것

1. **문서 하나를 바꿨는데 판정이 바뀐 기준은 짝마다 중앙값 9개(2~23개)입니다.** 에이전트 3이 변형 환자를 처음부터 다시 판정하면서 생긴 흔들림입니다. 실제 갱신 흐름에서는 바뀐 문서만 다시 판정해야 합니다(에이전트 3 `--changes`). 이 흔들림이 갱신 신호를 가립니다. 예를 들어 SYN-0002 → SYN-1791은 대상 제외 기준이 PASS → UNKNOWN으로 바뀌었는데, 다른 기준이 다시 판정되면서 미확인 개수가 상쇄되어 환자용 문장이 하나도 바뀌지 않았습니다.
2. **제외 기준의 기록 충돌이 환자에게는 개수 +1로만 전달됩니다.** SYN-4657·SYN-3363은 제외 기준이 CONFLICT가 되었는데, 환자용에는 "확인할 항목 N개"만 하나 늘었습니다. "환자용에 보일 범위"(키트 README 6장 4번)를 정할 때 CONFLICT는 개수와 따로 한 문장으로 쓰자는 근거가 됩니다.

## 2층. 전문가 평가 (점검표, 표본 10~20명분)

> 진행안·표본·평가표·계산 스크립트는 `EVAL2_PROTOCOL.md`(a6-0.4.5). dev 기본 환자 12명, 의료진용 문장 평가 6명. 평가자는 팀이 정합니다.

- **환자용**: PEMAT(이해 용이성·행동 가능성), CDC Clear Communication Index, KGCP 점검표, 치료적 오해 항목.
- **의료진용**: 문장마다 근거 노드 대비 "지지됨 / 일부 / 근거 없음 / 모순"을 매기고, 오류에는 심각도(치명·중대·경미)를 붙입니다.
- **일치도**: 4단계가 순서형이므로 가중 κ(평가자 2명) 또는 Krippendorff α(순서형, 평가자 3명 이상)를 보고합니다.
- **눈가림**: 평가자에게 틀 문장인지 LLM인지 가리고, 순서를 섞어 보여 줍니다.
- **LLM 채점기**: 사람 라벨과의 일치도를 먼저 보고한 뒤에만 확대합니다.

## 3층. 사용자 과제 평가 (계획)

- **환자용 이해도 퀴즈**: 문항은 사실 묶음에서 자동으로 만듭니다(참여 확정 여부, 위약·무작위, 남은 확인 사항, "조건 맞음 = 효과" 오해). 같은 사람이 틀 문장과 LLM 브리핑을 둘 다 읽는 구조로 비교합니다.
- **의료진용 과제**: 등록 전 확인할 항목을 적게 하고 정확도와 시간을 잽니다. 원 그래프를 보는 조건과 비교합니다.
- **IRB**
  - 「생명윤리법 시행규칙」 제13조 ①: 개인식별정보를 수집·기록하지 않고 침습이 없는 연구는 면제될 수 있습니다.
  - 같은 조 ②: 「의약품 등의 안전에 관한 규칙」 [별표 4] 제2호 더목의 취약한 시험대상자가 참가하면 면제가 안 됩니다. 여기에 의과대학·한의과대학·약학대학·치과대학·간호대학 학생이 포함됩니다.
  - 면제 여부는 연구자가 정하지 않고 학교 IRB에 신청해 판단받습니다. 참가자는 해당 학과 밖에서 모집하는 것을 기본으로 하고, 그 경우에도 면제를 신청합니다.
