## 2. 환자용 글: 규정

「의약품 등의 안전에 관한 규칙」 [별표 4] 의약품 임상시험 관리기준(KGCP), 2022-12-07 기준. ✅

| 조항 (제7호 아목) | 내용 | 브리핑 규칙 (`agent6/rules.py`) |
| --- | --- | --- |
| 10) 가) | 연구라는 사실 | `research_not_treatment` |
| 10) 다) | 무작위배정 확률 | `randomized` (확률 값은 아직 문구에 없음: ⓪ 기록에 배정 비율이 없을 때가 많음) |
| 10) 아) | 기대 이익, 없으면 그 사실 | `no_benefit_promise` |
| 10) 자) | 다른 치료방법 | `voluntary` (지금 치료를 그대로 받을 수 있음), `ask_alternatives` (다른 치료방법을 의료진에게 물어보도록 안내). 다른 치료방법 자체는 그래프에 없어 쓰지 않음 |
| 10) 파) | 자발적 참여와 언제든 철회 | `voluntary`, `withdraw` |
| 3) | 강요·부당한 영향 금지 | `BANNED` 금지 표현 |
| 6) | 쉬운 용어 | 환자용 문장 기준 |
| 라목 1)·3) | 대상자에게 주는 서면 정보와 모집 광고는 IRB 심사 대상 | 한계로 기록: 실제로 쓰면 브리핑 문구 자체가 IRB 검토를 받아야 할 수 있음 |

`placebo`(위약)는 KGCP 항목이 아니라 이해도 근거(3장 Tam et al.)로 넣은 문구입니다. 세부 조항 번호는 2026-10-30 원문 확인(합성 담당).

자주 틀리는 인용 (지난 문헌 검토에서 잡은 것):

- 동의 항목은 제7호 **아목 10)**에 있습니다. 가목이 아닙니다.
- "반감기 ×5", "28일" 같은 휴약 기간은 KGCP에 없습니다.

## 3. 환자용 글: 이해와 오해

| 근거 | 내용 | 상태 |
| --- | --- | --- |
| Tam et al. 2015 메타분석 (동의 이해도, 30년 자료) | 위약과 무작위배정에 대한 이해가 특히 낮음 → `placebo`·`randomized` 문구를 시험마다 넣는 이유 | 📄 |
| PLoS ONE 2017 무작위 시험 | 연구와 치료의 차이를 먼저 설명해도 참여 의향이 유지됨 → `research_not_treatment`를 맨 앞에 두는 이유 | ⚠️ 저자와 제목 특정 필요 |
| FDA, *Informed Consent* 최종 가이던스 (2023) | 동의는 이해하고 질문하고 스스로 결정하는 과정 → 판단 지원이지 참여 권유가 아님 | 📄 |
| CDC Clear Communication Index | 환자용 설명 채점표 후보. 알려진 것과 모르는 것을 나눠 쓰는 항목이 UNKNOWN을 숨기지 않는 설계와 맞음 | 📄 |
| 치료적 오해 (therapeutic misconception) | "조건이 맞음 = 나에게 효과 있음"으로 읽히지 않게 함 | 📄 (개념, 위 근거들에 기댐) |
| JCMC 후보: Chat but verify(검증 affordance), Walther 계열 warranting | 출처 표시가 신뢰를 올리는지, 적절하게 맞추는지 | ⚠️ 연구자 메모 단계 |

## 5. 평가 계획

| 대상 | 지표 | 상태 |
| --- | --- | --- |
| 순위 (dev 합성) | 순서 완전 일치, 첫 시험 일치 (`eval_variants.py --ranking`) | 기준선 40/55, 43/55 |
| 순위 (외부) | TREC NDCG@10, P@10 | 파이프라인 전체를 TREC 환자로 돌려야 함. 에이전트 3 TREC 실행은 있음 |
| 근거 연결 | 연결 없는 문장 수 (목표 0), 없는 ID 수 | `check_grounding`, 기준선 0 |
| 내용 일치 | 연결된 문장의 숫자·날짜·판정이 노드와 같은지 | 방법 미정 (README 6장 1번) |
| 규정 준수 | KGCP 항목 + 치료적 오해 + CDC 지표 점검표 | 필수 문구·금지 표현만 자동, 점검표는 아직 없음 |
| 이해도·신뢰 | 위약·무작위 이해, "조건 충족 = 효과" 오해 | 사용자 연구 과제. 참가자 모집 시 IRB: 「생명윤리법 시행규칙」 제13조 ① 면제 가능성이 있으나, 같은 조 ②에 따라 [별표 4] 제2호 더목의 취약한 시험대상자(의대·한의대·약대·치대·간호대 학생 포함)가 참가하면 면제 불가. 면제 여부는 학교 IRB에 신청해 판단받음 |

UNKNOWN의 이유, 다음 행동, 환자용 설명을 재는 공개 벤치마크는 없습니다. 그래서 dev 합성 정답과 위 점검표가 주된 평가 수단입니다.
